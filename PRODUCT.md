# Product: Hush

## Register
product

## Target Users
Developers, knowledge workers, and power users who want fast, private, hands-free voice dictation on the desktop. They run Hush in the background all day. They're technical enough to configure a hotkey and trust local-only software.

## Product Purpose
Hush is a local, offline voice-to-text tool that types dictated speech directly into whatever app the user is working in. No accounts, no subscription, no audio leaving the machine. Push-to-talk with a configurable hotkey.

## Brand Personality
Quiet confidence. Utility-first. Minimal footprint. Hush does one thing well and gets out of the way. It should feel like a precision tool, not a product.

## Tone
Understated. Functional. No filler text, no marketing language, no emoji. Every label earns its pixel. Copy is informational, not promotional.

## Anti-references
- SaaS onboarding screens with big hero metrics
- Purple gradient dashboards with glassmorphism panels
- Animated loaders that make users wait for choreography
- Identical card grids with icon + heading + text
- Any pattern that says "AI made this"

## Design Principles
- The overlay disappears when the user is done: it should feel weightless.
- Settings should be scannable at a glance: grouped, labeled, not overwhelming.
- Status is always visible but never intrusive.
- State changes are immediate; feedback is clear without being loud.
